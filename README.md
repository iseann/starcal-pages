# StarCal Pages

This folder contains the static GitHub Pages site for StarCal support and privacy information.

Support contact email:

`shenstudio1024@gmail.com`

Recommended App Store Connect URLs after GitHub Pages is enabled:

- Support URL: `https://<github-username>.github.io/<repo-name>/support.html`
- Privacy Policy URL: `https://<github-username>.github.io/<repo-name>/privacy.html`

In GitHub, enable Pages from:

`Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > Folder: /docs`
